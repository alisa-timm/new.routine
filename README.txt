# New Routine

Готовый одностраничный трекер на 75 дней.

## Структура

```text
New_Routine/
├── index.html
├── styles.css
├── script.js
└── README.txt
```

## Как запустить

1. Создай папку `New Routine`.
2. Положи в неё три файла:
   - `index.html`
   - `styles.css`
   - `script.js`
3. Открой `index.html` в браузере.

Никакого сервера, Python или базы данных для этой версии не требуется.

## Что уже работает

- 75 карточек.
- 7 карточек в каждом ряду.
- Стрелка справа от каждого ряда.
- Модальное окно с пятью пунктами недели.
- Можно отмечать пункты вручную.
- Кнопка «Отметить всю неделю».
- Каждая карточка дня нажимается отдельно: по умолчанию она голубая, после нажатия становится бордовой, повторное нажатие возвращает голубой цвет.
- Кнопка «Отметить всю неделю» отмечает все пункты недели и все карточки дней этой недели.
- Прогресс сохраняется в `localStorage`, поэтому после закрытия браузера отметки остаются.
- Адаптация под телефон, планшет и компьютер.

## Важный момент

Данные сохраняются в конкретном браузере на конкретном устройстве. Если открыть сайт на другом устройстве или очистить данные браузера, локальный прогресс там не появится.

Если позже понадобится аккаунт и синхронизация между устройствами, потребуется сервер и база данных.
